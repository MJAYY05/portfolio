นักศึกษาชั้นปีที่ 4 สาขาวิทยาการคอมพิวเตอร์ มหาวิทยาลัยกรุงเทพ (เกรดเฉลี่ยสะสม 3.54) มุ่งเน้นด้านความมั่นคงปลอดภัยไซเบอร์และวิทยาการข้อมูล ผ่านการรับรอง CompTIA Security+ และ CRTA มีประสบการณ์ลงมือทำจริงทั้งการตรวจจับภัยระดับโฮสต์ การวิเคราะห์ SIEM Log การตรวจจับความผิดปกติ การ Deploy ระบบบน Cloud และการพัฒนาด้วย Python กำลังมองหาโอกาสสหกิจศึกษาในสายงาน SOC / Blue Team เพื่อนำทักษะที่มีไปประยุกต์ใช้และพัฒนาต่อยอดร่วมกับทีมงานมืออาชีพ

ทักษะ

ทักษะหลัก: การเฝ้าระวังความปลอดภัยและวิเคราะห์ SIEM Log, การตรวจจับและรับมือเหตุการณ์ผิดปกติ, การประเมินช่องโหว่และทดสอบเจาะระบบ, การวิเคราะห์ทราฟฟิกเครือข่าย, พื้นฐานความปลอดภัยบน Cloud

เครื่องมือ (Advanced): Python, Git / GitHub

เครื่องมือ (Intermediate): Wazuh (SIEM), Sysmon, Wireshark, Burp Suite, Kali Linux, Microsoft Azure

อื่น ๆ: Microsoft Office (Proficient)

ทักษะรอง: การทำงานเป็นทีมข้ามสายงาน, การคิดวิเคราะห์และคิดเชิงวิพากษ์, การสื่อสารเชิงเทคนิคอย่างชัดเจน, การบริหารเวลาภายใต้กำหนดเวลา, การปรับตัวและเรียนรู้เร็ว

ภาษา: ภาษาไทย (Native), ภาษาอังกฤษ (ฟัง: Advanced, พูด: Intermediate)
